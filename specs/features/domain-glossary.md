## Summary

Terminology authority for **Neox Aspire** packages in this **public** repository (`neox-technology/aspire`). Host/contribution terms describe how this repo relates to **saas**. Feature-specific API names belong in their feature specs until promoted here.

## Terminology

| Term | Definition |
|------|------------|
| **Neox Aspire** | This Git repository (`neox-technology/aspire`). Public MIT libraries under the `Neox.Aspire.*` namespace. Not the Events product, Site overlay, Planner, Events AppHost, Events SDK, **Neox SaaS**, or the saas **test AppHost**. |
| **development host** | The saas Git repository (`neox-technology/saas`) that mounts this repo as a Git submodule (`aspire/`) so contributors can develop the packages there. The host does not own this product or its Arcade stack. Events may nest that host as `saas/` but still must not list these projects in `Neox.Events.slnx`. |
| **submodule contribution** | The preferred workflow: commit in this repository first, then update the gitlink in saas, then the saas gitlink in Events when working from that workspace. |
| **sample AppHost** | An isolated Aspire AppHost under `tests/` used as a package harness (for example `tests/efcore-migration-worker/*/apphost`). Not a product runtime, not the Events delivery AppHost, and not the saas **test AppHost** (`saas/tests/aspire`). Layout: `.cursor/rules/aspire-apphost.mdc`. |
| **Neox Aspire packages** | Packable NuGet libraries under the `Neox.Aspire.*` root namespace (hosting and non-hosting). MIT-licensed. Published to nuget.org via Trusted Publishing; pre-ship **daily** builds go to private GitHub Packages; local pack uses Arcade. |
| **hosting package** | A `Neox.Aspire.Hosting.*` library that AppHosts reference for Aspire resource/extension helpers. Lives under `src/hosting/` when present. |
| **Shipping** | Arcade package output bucket for packages intended for consumers (`artifacts/packages/<Configuration>/Shipping/`). Distinct from non-shipping / internal artifacts. |
| **daily** | Arcade prerelease label used by **release-private-publish** on `release/*`: packages version as `X.Y.Z-daily.{OfficialBuildId}` and publish to private GitHub Packages for pre-ship validation (not the public nuget.org identity). |
| **migration worker** | Reusable non-hosting DI helper (`Neox.Aspire.EntityFrameworkCore.MigrationWorker`) that runs EF Core `MigrateAsync` for one or more registered `DbContext` types in a single one-shot `BackgroundService` (registration order, sequential), then stops the host once via repeated `AddEfCoreMigrationService<TDbContext>()` calls. |
| **custom domain ops** | Hosting helpers (`Neox.Aspire.Hosting.Azure.CustomDomains`) that orchestrate ACA custom domain DNS and managed certificates via `aspire do` pipeline steps (plan/provision/deploy split for provider, zone, hostname add, env certs, and resource bind). |
| **DomainOps provider** | Aspire resource (`DomainOpsProviderResource` and **source-generated** subtypes such as Cloudflare/OVH/Route53) that selects an OctoDNS DNS **provider**, holds auth parameter bindings, and drives generated `octodns.yaml` + Docker image choice. Aligns with octoDNS terminology (**provider**, not provisioner). Types are emitted from the versioned OctoDNS provider catalogue. |
| **OctoDNS provider catalogue** | Checked-in JSON (`octodns-providers.json`) listing official `octodns/{flavor}` Docker providers (excluding all/etchosts/dyn) plus README-derived config settings; refreshed manually via `tools/octodns-provider-catalog`. |
| **prereq-domain** | Shared DomainOps pipeline gate registered by `AddDomainOpsProviderCore`; depends on Aspire `provision-{acaEnv.Name}` for the AppHost's `AzureContainerAppEnvironmentResource`. |
| **prereq-domain-{provider}** | Provider-specific DomainOps prereq (slug, e.g. `cloudflare`) that `docker pull`s `octodns/{provider}`; depends on `prereq-domain`. One step per provider slug, shared across resources of that type. |
| **plan-domain-{provider}** | Writes `octodns.yaml` for a provider (zone list from AppHost bindings; secrets as `env/VAR` refs only). |
| **plan-domain-{zone}** | Writes/upserts OctoDNS zone YAML for one registrable domain (aggregated across resources); dump live zone is internal. |
| **provision-domain-{zone}** | Runs OctoDNS sync for a zone (dry-run + Deletes=0 guard internal, then `--doit`); waits for DNS internally. |
| **plan-{env}-certificates** | Inventories managed certificates already on the ACA environment. |
| **provision-{env}-domains** | Gate that depends on all `provision-{resource}-domain-{dom}` steps for an ACA environment (no ARM). |
| **provision-{env}-certificates** | Creates missing managed certificates on the ACA environment in parallel (long wait); requires hostnames already on apps. |
| **plan-{resource}-domain-{dom}** | Prepares/validates the per-resource domain model (hostname, HTTP validation, expected cert name) without ARM calls. `{dom}` is the hostname slug (`.` → `-`). |
| **provision-{resource}-domain-{dom}** | Adds the custom hostname to the Container App without a certificate (`BindingType.Disabled`); no-op if the hostname already exists (does not detach an existing cert). |
| **deploy-{resource}-domain-{dom}** | Binds an existing managed certificate to the Container App hostname (SNI); rebinds if a different cert is already linked. |
| **deploy-domains** | Gate that depends on all `deploy-{resource}-domain-{dom}` steps; required by Aspire `deploy`. |
| **managed certificate** | Free DigiCert TLS certificate issued and renewed by Azure Container Apps for a validated custom domain. |
| **OctoDNS sync** | Applying **upserted** DNS records (create/update only; DomainOps never deletes) by running the official OctoDNS Docker image (`octodns/cloudflare`, `octodns/ovh`, …) with `octodns-dump` then `octodns-sync`, mounting generated config/zones and injecting credentials via container env (`env/VAR` refs in YAML). DomainOps does not treat the zone YAML as full zone ownership. |
| **Azure Entra ID hosting** | Shipping hosting package `Neox.Aspire.Hosting.Azure.EntraId` (`Neox.Aspire.Hosting.Azure` namespace). Public API is `AddAzureAppRegistration` plus `WithSupportedAccountType`, `AddScope`, `AddAppRole`, `AddWebApplication`, `AddSpaApplication`, `WithPermission`, `AddCertificate`, `WithKeyCredential`, **Entra ID instance**, `WithMicrosoftIdentityWebApplication`, and `WithEntraIdSpaApplication` (Aspire Azure `AzureProvisioningResource` + constructs from **Azure.Provisioning Graph**). Sample AppHost: `tests/azure-entraid/`. |
| **Keycloak hosting** | Shipping hosting package `Neox.Aspire.Hosting.Keycloak` (`Neox.Aspire.Hosting.Keycloak` namespace). Public API is `AddRealm` on upstream `KeycloakResource` (realm JSON + `WithRealmImport`), `AddJwtClient`, `AddOidcClient`, and `AddIdentityProvider` on `KeycloakRealmResource`, `WithKeycloakJwtBearer` for API env projection, and `WithKeycloakSpa` for SPA env projection. The sample harness uses upstream `Aspire.Hosting.Keycloak` (`AddKeycloak`) for the container and `Aspire.Keycloak.Authentication` in the sample API. Sample AppHost: `tests/keycloak/`. |
| **Keycloak realm resource** | Aspire child resource (`KeycloakRealmResource`) created by `AddRealm` on a upstream `KeycloakResource`. Implements `IResourceWithParent<KeycloakResource>`. Holds realm name and import directory; excluded from manifest. Named `{keycloakName}-{realm}`. |
| **Keycloak identity provider** | Aspire child resource (`KeycloakIdentityProviderResource`) created by `AddIdentityProvider` on a **Keycloak realm resource**. Implements `IResourceWithParent<KeycloakRealmResource>`. Maps to Keycloak realm-import `identityProviders` (`IdentityProviderRepresentation`: alias, providerId, config). Excluded from manifest. |
| **Keycloak Entra ID hosting** | Shipping bridge package `Neox.Aspire.Hosting.Keycloak.EntraId` (`Neox.Aspire.Hosting.Keycloak.EntraId` namespace). Public API is `AddEntraIdIdentityProvider` on a **Keycloak realm resource**, wiring an **Azure app registration resource** (plus **Entra ID instance** and **client secret**) as a Keycloak OIDC **Keycloak identity provider**. Deferred OIDC config is applied by a non-parented config gate that Keycloak `WaitFor`s. Unit tests: `tests/keycloak-entraid/`. |
| **Keycloak JWT client** | Aspire child resource (`KeycloakJwtClientResource`) created by `AddJwtClient` on a **Keycloak realm resource**. Confidential client for API JWT validation; projects `Keycloak__*` via `WithKeycloakJwtBearer`. |
| **Keycloak OIDC client** | Aspire child resource (`KeycloakOidcClientResource`) created by `AddOidcClient` on a **Keycloak realm resource**. Public client for browser/SPA auth code + PKCE; projects `KEYCLOAK_*` via `WithKeycloakSpa`. |
| **KEYCLOAK_ env convention** | Consumer env keys for a public-client SPA (`KEYCLOAK_URL`, `KEYCLOAK_REALM`, `KEYCLOAK_CLIENT_ID`) injected by `WithKeycloakSpa` from an OIDC client and the Keycloak AuthServerUrl endpoint. Vite samples expose them with `envPrefix` `KEYCLOAK_`. |
| **Keycloak realm provisioning** | Shipping CDK package `Neox.Keycloak.Provisioning.Realm` (`Neox.Keycloak.Provisioning.Realm` namespace). Source-generated JSON POCOs for Keycloak realm import (`RealmRepresentation`, `ClientRepresentation`, …). Not an Aspire hosting package. |
| **Keycloak realm OpenAPI catalogue** | Checked-in `openapi.json` / `index.json` snapshot of Keycloak Admin REST OpenAPI version **26.2.0**; refreshed manually via `tools/keycloak-realm-openapi-catalog`; consumed at build time by `Neox.Keycloak.Provisioning.Realm.Generators.Internal`. |
| **Azure app registration resource** | Aspire Azure resource (`AzureEntraIdAppRegistrationResource`) created by `AddAzureAppRegistration`. Provisions or references a Microsoft Entra ID application via `ConfigureInfrastructure` (`GraphApplication` / `GraphServicePrincipal` from **Azure.Provisioning Graph**). Existing apps use Aspire `AsExisting` / `RunAsExisting` / `PublishAsExisting` with Graph `uniqueName` (not ARM `name`). Outputs `clientId` and `objectId`. `AddScope` / `AddAppRole` / `AddWebApplication` / `AddSpaApplication` register child **Azure Entra ID scope** / **Azure Entra ID app role** / **Azure Entra ID web application** / **Azure Entra ID SPA application** resources; the parent module emits Graph `api.oauth2PermissionScopes`, `appRoles`, `web.redirectUris`, and `spa.redirectUris`. `WithPermission` on a consumer registration records Graph `requiredResourceAccess` against an in-model **Azure Entra ID permissible resource** and `WaitFor`s the exposer app registration. `WithKeyCredential` records Graph `keyCredentials` against an in-model **Asymmetric X.509 cert resource** and `WaitFor`s that cert. `WithSecret` creates an **Entra ID password credential resource** child that `WaitFor`s the registration then Graph `addPassword`. |
| **Azure Entra ID scope** | Aspire child resource (`AzureEntraIdScopeResource`) created by `AddScope` on an **Azure app registration resource**. Implements `IResourceWithParent<AzureEntraIdAppRegistrationResource>` and **Azure Entra ID permissible resource** (`Type` = Scope). Not an `AzureProvisioningResource`; has no Bicep module. Graph `oauth2PermissionScopes` entries are written only by the parent app registration’s infrastructure callback. |
| **Azure Entra ID app role** | Aspire child resource (`AzureEntraIdAppRoleResource`) created by `AddAppRole` on an **Azure app registration resource**. Implements `IResourceWithParent<AzureEntraIdAppRegistrationResource>` and **Azure Entra ID permissible resource** (`Type` = Role). Not an `AzureProvisioningResource`; has no Bicep module. Graph `appRoles` entries are written only by the parent app registration’s infrastructure callback. Member types use the `[Flags]` enum `AllowedMemberTypes` (`User`, `Application`). |
| **Azure Entra ID web application** | Aspire child resource (`AzureEntraIdWebApplicationResource`) created by `AddWebApplication` on an **Azure app registration resource**. Implements `IResourceWithParent<AzureEntraIdAppRegistrationResource>`. Not an `AzureProvisioningResource`; has no Bicep module. `WithRedirectUri(Uri)` accumulates Graph `web.redirectUris` entries written only by the parent app registration’s infrastructure callback. |
| **Azure Entra ID SPA application** | Aspire child resource (`AzureEntraIdSpaApplicationResource`) created by `AddSpaApplication` on an **Azure app registration resource**. Implements `IResourceWithParent<AzureEntraIdAppRegistrationResource>`. Not an `AzureProvisioningResource`; has no Bicep module. `WithRedirectUri(Uri)` accumulates Graph `spa.redirectUris` entries written only by the parent app registration’s infrastructure callback. Public-client platform (auth code + PKCE); no implicit grant on create Bicep. |
| **Azure Entra ID permissible resource** | Interface `IAzureEntraIdPermissibleResource` (`Id` + `Type` Scope or Role) implemented by **Azure Entra ID scope** and **Azure Entra ID app role**. Consumed via `WithPermission(IResourceBuilder<T>)` (`T : IAzureEntraIdPermissibleResource`) to emit Graph `requiredResourceAccess` on the consumer **Azure app registration resource**. |
| **Asymmetric X.509 cert resource** | Aspire resource (`AsymmetricX509CertResource`) created by `AddCertificate` on `IDistributedApplicationBuilder`. Not an `AzureProvisioningResource` and not parented to an app registration. Looks up a certificate in `StoreName.My` at `StoreLocation.CurrentUser` or `LocalMachine` by thumbprint and publishes `Running` or `FailedToStart`. Does not create or upload the certificate. |
| **Entra ID password credential resource** | Aspire child resource (`EntraIdPasswordCredentialResource`) created by `WithSecret` on an **Azure app registration resource**. Implements `IResourceWithParent<AzureEntraIdAppRegistrationResource>`. Not an `AzureProvisioningResource`; `ExcludeFromManifest`. Does not Aspire-`WaitFor` the parent; run-mode initialize waits for parent `Running` via `ResourceNotificationService`, then Graph `addPassword`, fills the bound secret `ParameterResource`, and persists AppHost user secrets. Publishes `Running` or `FailedToStart`. |
| **Key credential** | Public certificate bound on an **Azure app registration resource** via `WithKeyCredential`; Graph `keyCredentials` (`type: AsymmetricX509Cert`, `usage: Verify`). Distinct from a **client secret**. The registration `WaitFor`s the **Asymmetric X.509 cert resource**. |
| **Client secret** | Confidential-client password for an **Azure app registration resource**, bound via `WithSecret` to a secret Aspire `ParameterResource` through an **Entra ID password credential resource**. Created in run mode after the parent is ready via Graph REST `addPassword`; value is written into the parameter and AppHost user secrets (`Parameters:{name}`). Injected as `{sectionName}ClientSecret` (and optional `ClientCredentials` ClientSecret entries) by `WithMicrosoftIdentityWebApplication` / `WithEntraIdSpaApplication`. Not emitted as Graph Bicep `passwordCredentials`. |
| **Azure.Provisioning Graph** | Shipping CDK package `Neox.Azure.Provisioning.Graph` (`Neox.Azure.Provisioning.Graph` namespace). Source-generated `Azure.Provisioning` constructs for Microsoft Graph Bicep resources (`GraphApplication`, `GraphServicePrincipal`, nested `GraphWebApplication` / `GraphSpaApplication`, and the rest of Graph v1.0). Not an Aspire hosting package. |
| **Microsoft Graph Bicep types catalogue** | Checked-in `types.json` / `index.json` snapshot of [msgraph-bicep-types](https://github.com/microsoftgraph/msgraph-bicep-types) Graph v1.0 types version **1.0.0**; refreshed manually via `tools/msgraph-bicep-types-catalog`; consumed at build time by `Neox.Azure.Provisioning.Graph.Generators.Internal`. |
| **OAuth2 permission scope** | Exposed delegated permission on an Entra application; Graph `api.oauth2PermissionScopes`. Azure Entra ID hosting: `AddScope` on `AzureEntraIdAppRegistrationResource` (child `AzureEntraIdScopeResource`). |
| **App role** | Exposed application role on an Entra application; Graph `appRoles`. Azure Entra ID hosting: `AddAppRole` on `AzureEntraIdAppRegistrationResource` (child `AzureEntraIdAppRoleResource`; `[Flags]` `AllowedMemberTypes` User and/or Application). |
| **API permission** | Consumer **Azure app registration resource** dependency on an in-model **Azure Entra ID permissible resource** (`WithPermission`); Graph `requiredResourceAccess` (type Scope or Role). The consumer `WaitFor`s the exposer app registration (provision `DependsOn` via the exposer `ClientId` Bicep parameter). |
| **Entra ID instance** | Login authority host injected as `{sectionName}Instance` (`EntraIdInstance`). `Workforce` is `https://login.microsoftonline.com/`. `Ciam` is `https://{tenantSubdomain}.ciamlogin.com/` from a string or an Aspire `ParameterResource` (not read at `Configure()`). Required first argument of `WithMicrosoftIdentityWebApplication` and `WithEntraIdSpaApplication`. |
| **AzureAd__ env convention** | Consumer env keys aligned with Microsoft.Identity.Web (`AzureAd__Instance`, `AzureAd__TenantId`, `AzureAd__ClientId`, optional `AzureAd__Audience` / `AzureAd__ClientCredentials__*` / `AzureAd__ClientSecret`) injected by `WithMicrosoftIdentityWebApplication` from an **Entra ID instance** plus an **Azure Entra ID web application** (parent `clientId`, AppHost `Azure:TenantId`, store **key credential**s, **Entra ID password credential**s). |
| **ENTRA_ env convention** | Consumer env keys for a SPA (`ENTRA_Instance`, `ENTRA_TenantId`, `ENTRA_ClientId`, `ENTRA_LoginScopes`, optional `ENTRA_Audience` / `ENTRA_Scope` / `ENTRA_ClientSecret`) injected by `WithEntraIdSpaApplication` from an **Entra ID instance** plus an **Azure Entra ID SPA application** (parent `clientId`, AppHost `Azure:TenantId`, interactive login scopes `openid offline_access` as `ENTRA_LoginScopes`, first in-model Scope **API permission** as `ENTRA_Scope`, optional parent **Entra ID password credential** as `ENTRA_ClientSecret`). Vite samples expose them with `envPrefix` `ENTRA_`. |
